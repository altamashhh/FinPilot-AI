# FinPilot AI (WealthAI) - Premium Corporate Wealth Tracker

FinPilot AI (frontend branded as **WealthAI**) is a cutting-edge personal finance and budgeting assistant powered by generative AI. By combining a modern React frontend with a robust FastAPI backend and Google Gemini, FinPilot AI offers an unparalleled capability for managing transactions, projecting budgets, tracking financial health, and receiving intelligent, agentic financial advice.

---

## 1. Feature List

- **Agentic AI Financial Advisor**: Powered by Google Gemini, the app delivers highly contextualized insights and a conversational chatbot interface to analyze your spending history.
- **Smart Dashboard Analytics**: Track your net savings, budget utilization, and dynamically categorized expenses using interactive metrics and D3-style donut charts.
- **Transaction Auto-Categorization Engine**: Automatically classifies new transactions (e.g., classifying "Swiggy" as "Food", "Uber" as "Travel") based on keyword rules.
- **Budget Management**: Establish monthly spending limits per category, complete with automatic overspend tracking.
- **JWT-Based Authentication**: Secure role-based data isolation ensuring users only see their own private financial records securely.
- **Responsive Premium UI**: A highly polished, glassmorphic UI equipped with smooth micro-animations built utilizing modern React and Tailwind styling principles.

---

## 2. Project Architecture

The system utilizes a decoupled Client-Server architecture:

- **Frontend (`/wealthai`)**: 
  - **Framework**: React (Vite)
  - **Styling**: Vanilla CSS (Tailwind principles) with Lucide React icons
  - **State Management**: Centralized React State with `localStorage` based session persistency via a secure API abstraction layer.
- **Backend (`/Backend`)**: 
  - **Framework**: FastAPI (Python)
  - **Database**: SQLite with SQLAlchemy ORM (Asynchronous database connections)
  - **Authentication**: JWT (JSON Web Tokens) with PassLib (Bcrypt)
  - **AI Engine**: Google GenAI (`gemini-2.5-flash`) SDK for conversational LLM advice.

## 3. Installation Guide

### Prerequisites
- Node.js (v18+)
- Python (3.10+)
- Gemini API Key

### Backend Setup
1. Open a terminal and navigate to the backend directory:
   ```bash
   cd "Backend"
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # On Windows
   venv\Scripts\activate
   # On Mac/Linux
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Configure environment variables:
   Create a `.env` file in the `Backend` directory containing your Gemini API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
5. Start the server:
   ```bash
   python -m uvicorn app:app --port 8000 --reload
   ```

### Frontend Setup
1. Open a new terminal and navigate to the frontend directory:
   ```bash
   cd "wealthai"
   ```
2. Install Node dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Access the application at `http://localhost:3000`.

## 4. API Documentation

The backend exposes the following RESTful endpoints (Base URL: `http://localhost:8000`).
All protected endpoints require an `Authorization: Bearer <token>` header.

### Authentication
- `POST /auth/register` - Registers a new user.
- `POST /auth/login` - Authenticates a user and returns a JWT token.
- `GET /auth/me` - (Protected) Returns the current user's profile.

### Dashboard
- `GET /dashboard/` - (Protected) Returns the user's aggregated financial metrics, category spending, and budget utilization.

### Transactions
- `GET /transactions/` - (Protected) Lists all transactions for the user.
- `POST /transactions/` - (Protected) Creates a new transaction. (Automatically categorizes if category is left blank).
- `GET /transactions/{id}` - (Protected) Retrieves a specific transaction.
- `PUT /transactions/{id}` - (Protected) Updates a transaction.
- `DELETE /transactions/{id}` - (Protected) Deletes a transaction.

### Budgets
- `GET /budgets/` - (Protected) Lists all user budgets.
- `POST /budgets/` - (Protected) Creates a new budget.
- `GET /budgets/{id}` - (Protected) Retrieves a specific budget.
- `PUT /budgets/{id}` - (Protected) Updates a budget.
- `DELETE /budgets/{id}` - (Protected) Deletes a budget.

### AI & Insights
- `GET /insights/` - (Protected) Generates predictive alerts, smart recommendations, and dynamic health scores based on recent spending behavior.
- `POST /ai/advice` - (Protected) Fetches a customized financial summary generated by Google Gemini using user data context.
- `POST /chat` - (Protected) Interfaces with the Gemini AI chatbot to answer natural language queries regarding the user's transaction history.

*(Access the interactive Swagger UI at `http://localhost:8000/docs` while the backend is running).*
